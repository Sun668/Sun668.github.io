五、RuntimeFactory 解决什么问题

如果每次建立连接时都在 Server 中手动创建 Registry、Approval、Engine、Session 和 Reporter，Server 很快会变成依赖组装代码的集合。

RuntimeFactory 统一创建每个 Runtime 所需的依赖：

每个独立连接都应该拥有自己的 Runtime、Session、Registry、Approval Handler、GrantStore 和 Reporter。

Provider 可以由多个 Runtime 共享，但 Session、Reporter 和审批状态不能错误共享。
